질문 : ESS 데이터가 CSV로 있는데 파일을 열면 날짜 행이 ######으로 보이는데 git허브에 파일 올리면 #####을 git허브가 읽을 수 있어?
답변 : 응! GitHub는 ######이 아니라 실제 날짜 데이터를 읽을 수 있어. 걱정하지 않아도 돼.

######은 보통 엑셀에서 날짜가 들어 있는 열의 너비가 좁아서 표시되는 현상이야. 실제 데이터가 사라진 것은 아니야.

예를 들어 엑셀에서 다음과 같이 보인다면,
엑셀 화면	실제 데이터
######	2024-01-01
######	2024-02-01
######	2024-03-01

GitHub에 CSV 파일을 올리면 실제 저장된 날짜 값이 그대로 올라가.

질문:지역별 에너지저장장치(ESS) 일단위 충전 및 방전 실적 CSV 파일이 있는데 방전량 합계가 어떤 날이 0인데 이게 결측치가 아니야? 다른 날들은 200쯤되는데
답: 방전량 합계가 0이라고 해서 반드시 결측치는 아니야. 실제로 그날 ESS에서 방전이 발생하지 않았을 가능성도 있어.

다음 세 가지를 구분해야 해.
1. 실제 0: 해당 날짜에 방전 실적이 없었던 경우
2. 결측치: 데이터가 수집되지 않았거나 값이 누락된 경우
3. 집계 결과 0: 여러 지역의 방전량을 합산했지만 실제 방전량이 0인 경우
특히 다른 날의 방전량 합계가 약 200인데 특정 날짜만 0이라면 확인이 필요해.
확인하는 방법
- 같은 날짜의 충전량도 0인지 확인하기
- 해당 날짜의 지역별 방전량이 모두 0인지 확인하기
- CSV 원본에서 빈칸이 0으로 변환된 것은 아닌지 확인하기
- 다른 날짜에도 방전량이 0인 날이 있는지 확인하기
탐구 분석에서는 실제 0이라면 삭제하지 않는 것이 좋아. 실제 ESS 운영 실적을 반영하는 데이터이기 때문이야. 반면 결측치라면 별도로 처리해야 해
